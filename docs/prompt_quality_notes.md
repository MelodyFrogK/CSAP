# 프롬프트 품질 점검 노트 (1단계: 명세서 작성)

실제 업로드 KISA 명세서의 점검항목 2건과 데모 기업 문서로 출력 품질을 점검하고,
그 결과 `app/core/prompts.py` 의 시스템 프롬프트를 보강했다. (실 API 키 미보유 환경이라
도메인 기준에 따른 기대 출력을 기준선으로 사용)

## 점검 케이스

기업 문서(요약): 정보보호 정책 수립·CISO 승인·포털 공지 / 계정 등록·변경·삭제 절차·분기
점검 / 관리자·VPN MFA / 가상자원 변경관리·테넌트 격리. **공급망·백업·암호·교육 내용은 없음.**

### 케이스 A — 1.1.1 정보보호 정책 수립 (직접 근거 있음)

기대 출력:
```json
{
  "operation": "운영",
  "status": "- 클라우드 정보보호 정책 및 시행 지침·절차·매뉴얼을 문서화하여 운영\n- 정책은 CISO 승인 하에 제·개정, 사내 포털로 전 임직원 공지",
  "related_docs": "당사 정보보호 정책서(및 하위 지침·절차·매뉴얼)",
  "evidence": "정보보호 정책서, 시행문서(지침/절차/매뉴얼), 포털 공지 화면",
  "improvement": "- 시행문서의 문서명/버전/제·개정 이력 명시 권장"
}
```

### 케이스 B — 4.1.1 공급망 관리 정책 수립 (근거 없음)

기대 출력:
```json
{
  "operation": "확인불가",
  "status": "",
  "related_docs": "",
  "evidence": "",
  "improvement": "- 공급망(외부 위탁·협력업체) 보안 요구사항·관리정책 근거 미확인\n- 공급망 위험 식별 및 보안대책(계약상 보안요구사항, 데이터 보호, 시설·네트워크 장애 대응, 위탁 보안)을 포함한 관리정책 보완 필요"
}
```

## 발견된 핵심 리스크와 대응

| 리스크 | 내용 | 프롬프트 대응 |
|---|---|---|
| **주제 환각** | 짧은 문서에서는 모든 항목에 동일 발췌가 전달됨. 발췌에 '정책 수립' 표현이 있다는 이유로 *공급망* 항목까지 "운영"으로 오판 | "발췌에 단어가 보인다고 충족 아님 → 점검항목이 묻는 *구체적 주제*의 직접 근거가 있을 때만 충족" 규칙 + 공급망 반례 명시 |
| 판정 모호 | 운영/미운영/해당없음/확인불가 경계 불명확 | 4개 값의 판정 기준을 명시. 근거 없으면 확인불가 |
| 형식 일관성 | 현황/보완 서술형으로 길어짐 | 개조식('- ') 2~4줄로 제한, 필드별 작성 지침 |
| 결정성 | 들쭉날쭉한 출력 | temperature=0, 2개 few-shot 예시(운영/확인불가)를 시스템 프롬프트에 포함(Anthropic 프롬프트 캐싱으로 비용 절감) |

## 실측 결과 (claude_cli 공급자, 실제 Claude 모델)

위 보강 프롬프트를 실제 모델로 검증(표본 4건). **모두 의도대로 동작 확인.**

| 점검항목 | 문서 근거 | 운영여부 | 평가 |
|---|---|---|---|
| 1.1.1 정보보호 정책 수립 | 있음 | 운영 | 현황 정확. "외부 업무 관련자 제공은 미확인"까지 해설 세부요건 대조 |
| 8.1.1 물리적 보호구역 지정 | 없음 | 확인불가 | **현황 빈칸(환각 없음)**. 보완사항만 해설 기반으로 상세 도출 |
| 9.1.1 가상자원 관리 | 있음(가상화 매뉴얼) | 운영 | 매뉴얼 근거로 정확 판정. DaaS 데이터 삭제 등 누락분 보완 제시 |
| 14.1.1 보안서비스 수준 협약 | 없음 | 확인불가 | 현황 빈칸. 국가기관 SLA 표준 요구사항(국내저장·국정원 협조 등) 보완 도출 |

결론:
- **주제 환각 방지가 핵심 목표대로 작동** — 근거 없는 항목은 운영현황을 비우고 확인불가 처리.
- 근거 있는 항목은 발췌 사실에 부합하는 현황 + 출처/증적 제시.
- 보완사항이 점검항목 해설의 세부 요구사항과 대조되어 매우 구체적.
- 추가 프롬프트 수정 없이 운영 가능 수준. (보완사항이 다소 길어 도메인 지식을 적극 활용 →
  필요 시 길이 제한 지시를 추가할 수 있음)

## 실 API 키로 검증하는 법

```bash
export ANTHROPIC_API_KEY=sk-ant-...
export CSAP_LLM_PROVIDER=anthropic
python -m app.cli --template "명세서.xlsx" --out 결과.xlsx 회사문서.pdf
```

검증 시 확인 포인트:
1. 공급망/백업/암호 등 **문서에 없는 주제**가 "확인불가"로 나오는가(환각 없는지).
2. 정책/접근통제 등 **근거 있는 주제**의 현황이 발췌 사실과 일치하는가.
3. 보완사항이 점검항목 *해설의 세부 요구사항*과 대조되어 구체적인가.

> 출력은 초안이며, 제출 전 담당자 검토 필수.
